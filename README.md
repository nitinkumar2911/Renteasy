# RentEasy - Rental Platform (MERN Stack)

RentEasy is a full-stack MERN application that enables users to list, browse, and rent vehicles or equipment for specific date ranges.

## Project Structure

- `backend/` - Express API server and database connection logic
- `frontend/` - React user interface powered by Vite

## Tech Stack
- **Database**: MongoDB
- **Backend**: Express.js, Node.js
- **Frontend**: React.js
- **Cloud Infrastructure**: AWS S3
